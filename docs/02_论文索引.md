## 三个可发表 Niche

1. **Mode-Aware Forgetting for VLA Replay Buffer** ⭐⭐⭐ — 聚类失败模式 + capability check + 整模式遗忘（对应 HEARS D 支柱）。CoRL 2026 / ICLR 2027。
2. **Segment-level Mixed SFT+RL** ⭐⭐⭐ — 失败 rollout 段级利用，识别"局部正确但最终失败"（对应 HEARS C 支柱，核心创新）。
3. **PLD × Episodic Memory × Skill LoRA Library** — PLD 框架下加 episodic 检索 + LoRA 技能库（对应 HEARS B+E 支柱）。
