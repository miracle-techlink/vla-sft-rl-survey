# RL/SFT 训练动力学机制解读

> 综合本地调研（统一理论 / 诊断 / 混合综述 30+ 篇）与 2025–2026 最新研究。本章不罗列方法，而是回答一个问题：**当我们做 SFT 和 RL 时，模型参数、输出分布、熵在"物理上"到底发生了什么，以及这对 VLA 真机后训练意味着什么。**

---

## 1. 核心对立：SFT「记忆/压缩」 vs RL「探索/扩展」

源头是 Chu et al. 的标杆实证 [SFT Memorizes, RL Generalizes (arXiv:2501.17161, ICML 2025)]：在 GeneralPoints（算术）和 V-IRL（导航）上做规则/视觉变体 OOD 测试，发现 **SFT 倾向记住训练分布、OOD 即崩；以结果奖励训练的 RL 则能跨变体泛化**，甚至改善底层视觉识别。

但这句口号已被 2025 下半年研究**反复修正**，需区分三层：

| 层面 | SFT 在做什么 | RL 在做什么 |
|---|---|---|
| 目标 | 最大化专家轨迹似然 `−log p(y\|x)` | 最大化期望奖励 `E[R]` |
| 数据来源 | off-policy（固定专家数据） | on-policy（自身采样 rollout） |
| 分布效果 | **扩张/同质化**（覆盖更多 mode） | **压缩/锐化**（集中到高奖励 mode） |
| 泛化来源 | 模仿，易过拟合训练分布 | 偏置采样到正确路径，提升采样效率 |
| 熵 | 不直接约束，常使熵升高/漂移 | 系统性降低熵（探索预算被消耗） |
| 风险 | OOD 遗忘、格式锁死 | 熵坍缩、mode collapse、多样性丧失 |

**物理直觉**：SFT 是"把概率质量铺到老师走过的所有路径上"（拟合更宽分布）；RL 是"把质量从错误路径抽走、堆到对的路径上"（再分配，不创造新路径）。二者**方向相反**，这正是它们互补又互相覆盖的根因。

> **关键澄清**：「SFT 记忆、RL 泛化」是**现象级**总结，不是机制级真理。§2/§5 给出更准确版本——SFT 的问题不在"记忆"而在"OOD 早峰后遗忘"，RL 的作用很大程度是"修复"而非凭空泛化。

## 2. 分布层面动力学：sharpening vs expansion

### 2.1 两个对偶现象

- **RL Squeezes / SFT Expands** [arXiv:2509.21128]：1.5B–14B 推理模型上做 reasoning-graph 分析，**RL 把推理功能集中到少数关键 step（concentrate），SFT 把功能均摊到许多 step（homogenize）**。
- **参数层面对偶**——MIFO（arXiv:2510.04454）：**SFT 参数更新冗余且幅度大，RL 更新节俭且幅度小**，故后续 SFT 会"覆盖"先前 RL 学到的东西。这解释了两阶段顺序敏感、需要参数冻结来保护 RL-critical 权重。

### 2.2 RL 到底"扩展"还是"只锐化"？——本章最大争议（需向导师呈现两面）

**观点 A（只锐化，不创造）** [Does RL Really Incentivize Reasoning Beyond the Base Model? arXiv:2504.13837, NeurIPS 2025]：pass@1 RL 胜 base，但 **pass@k（大 k）base 反超**；RL 可解集是 base 可解集的**子集**；训练越久 pass@1 升、pass@256 反降——**采样效率提升，但能力边界收窄**。

**观点 B（足够长能扩展）** [ProRL, arXiv:2505.24864, NVIDIA]：用 KL 控制 + 参考策略重置 + 多样任务训 2k+ step 后，**在 base 怎么采都失败（pass@k=0）的问题上 RL 也能解**，出现分布外新解。

**调和**：短/常规 RL = 锐化（A 对）；长程 + 强探索保持（防熵坍缩）+ 参考重置的 RL = 可能扩展（B 对）。**决定 RL 是"锐化"还是"扩展"的开关，是探索预算（熵）是否被维持**——引出 §4。

```
机制图解（文字版）：
  base 分布:   ░░▓░░▓▓░▓░░░  (宽，含正确路径但稀疏)
  SFT 后:      ░▓▓▓▓▓▓▓▓▓░░  (更宽更平，铺满老师路径，含 OOD 漂移)
  常规 RL 后:  ░░░░░██░░░░░  (尖峰，锐化到高奖励 mode，pass@k↓)
  长程 RL:     ░░░░██░░░█░░  (尖峰 + 偶发新峰 = 边界扩展)
```

## 3. 梯度与 token 层面动力学

机制最干净、对工程最可操作的一层。

### 3.1 SFT 的梯度：全 token 均匀正梯度，但隐含坏 reward

[DFT / On the Generalization of SFT: A RL Perspective with Reward Rectification (arXiv:2508.05629, ICLR 2026)]：标准 SFT 梯度 ≡ 一个**隐式奖励 = 1/p(y|x)** 的策略梯度。模型越不确定（p 小）的 token 反而被赋予越大有效奖励 → **逆概率加权 + 无界方差**，这是 SFT 泛化差的根因。

**DFT 修正（一行代码）**：`loss = −p(y|x).detach() · log p(y|x)`（标准为 `−log p(y|x)`）。把有偏、概率依赖的不稳定更新校正为均匀加权的稳定更新，使 SFT 获得接近 RL 的泛化。

**物理直觉**：SFT 默认"每个 token 同等重要"，但梯度数学上把权重偷偷压在低概率（难）token 上，导致过拟合罕见模式；DFT 把这个偏置抹平。

### 3.2 RL 的梯度：优势加权 + 负梯度

- RL（GRPO/PPO）梯度 = **优势加权**：正优势 token 推高、负优势 token 压低。SFT 只有正梯度（只"抬"对的，不"压"错的），这是泛化差异的梯度级根源。
- **负梯度 = 锐化的真正动力** [On the Effect of Negative Gradient in GRPO, arXiv:2505.18830]：对错误路径施加大负梯度，在分布"谷地"产生 **squeezing effect**，把质量从错误 mode 抽走——RL 锐化的微观机制，SFT 做不到。
- 副作用 **Lazy Likelihood Displacement**：朴素惩罚错误响应所有 token 会让正确响应似然不升反降；解法是按 token 贡献下调惩罚（与 §3.1 token 级重加权同思想）。

### 3.3 统一视角

[UPGE / HPT (arXiv:2509.04419)]：SFT、PPO、GRPO 都是**同一个统一策略梯度估计器**的特例，仅 4 组件取值不同。**SFT 不过是"优势恒为 +1、无负样本"的退化 RL**——这是"2026 年 SFT 不再是独立概念，而是 RL loss 的一个加权项"趋势的理论基座。

## 4. 熵动力学

### 4.1 熵坍缩是 RL 的核心瓶颈

[The Entropy Mechanism of RL for Reasoning LLMs (arXiv:2505.22617, PRIME-RL)]：无干预 RL 中**策略熵早期急剧下降**，探索枯竭、性能饱和。拟合经验定律 **R = −a·e^H + b**：性能与熵满足指数关系，**性能用熵"换"**；H→0 时性能触顶 R=−a+b，**天花板在熵耗尽前就可预测**。解法 Clip-Cov / KL-Cov：只对高协方差 token 裁剪/KL 惩罚，保住探索。

**物理直觉**：熵就是 RL 的**探索预算**，花光就跳不出当前 mode——这是 §2.2"常规 RL 只锐化"的微观解释。ProRL 能扩展边界，本质是通过 KL 控制 + 参考重置**避免熵过早耗尽**。

### 4.2 熵作为 SFT/RL 的判别信号

- [SRFT (arXiv:2506.19767)]：用 policy entropy 动态调 SFT 权重——熵高（不确定）降 SFT 避免分布失配，熵低（自信）加大 RL 探索。**SFT 引起"粗粒度全局分布漂移"，RL 引起"细粒度选择性优化"，熵正好区分两个粒度**。
- [RLSD / Self-Distilled RLVR (arXiv:2604.03128)]：方向/幅度解耦能**保持健康熵、避免 entropy collapse**——环境奖励定方向、教师 logit gap 只调幅度，监督信号不挤压探索。

## 5. 灾难性遗忘与 OOD：RL 如何"修复" SFT

对 §1 口号最重要的修正，核心 takeaway。

[RL Fine-Tuning Heals OOD Forgetting in SFT (arXiv:2509.12235)]：真相不是"SFT 记忆 / RL 泛化"，而是 **OOD 性能在 SFT 早期就达峰，随后随 ID 继续优化而下降（OOD forgetting）；RL 阶段在"恢复"被遗忘的能力**，而非凭空创造。**谱分析**：遗忘对应权重矩阵**奇异向量的旋转**（几何漂移），而**奇异值基本不变**（幅度没丢、方向丢了）。重要限制：RL 只能从**有限范围的 SFT checkpoint** 修复——SFT 过度了就救不回来。

与 [Quagmires (arXiv:2510.01624, NeurIPS 2025)] 的 1M GPU 小时结论呼应：**高 SFT 分数会误导你**，极端情况下 SFT 后 RL 反比直接 RL 更差；应改看 held-out 泛化 loss 和 pass@large-k。

**物理直觉**：RL 在这里是**隐式正则化**（类似 dropout），对抗 SFT 的 over-specialization——通过旋转奇异向量回到泛化方向，而非改变表征能量。**所以 SFT 别练过头：在 OOD 峰附近就切 RL。**

> VLM 反例提醒 [Synergy Dilemma, arXiv:2507.07562]：在 reasoning VLM 上，两阶段/交替/渐进式 naive 混合**三种都无真协同**，只是不同维度 trade-off；修复效应需 token 级细粒度控制（CHORD/RLSD）才稳。

## 6. 何时用 SFT、何时用 RL、何时混合

### 6.1 经验准则

| 场景 | 该做什么 | 依据 |
|---|---|---|
| 连格式都不对、0 奖励率高 | **先 SFT** 稳定输出格式 | 2501.17161：SFT 是 RL 前提 |
| 已有格式、要泛化/采样效率 | **切 RL** | 2501.17161 / 2504.13837 |
| 难题所有 rollout 全失败（0 梯度） | fallback SFT 或注入 expert prefix | SuperRL / BREAD |
| 想要长期边界扩展 | **长程 RL + 维持熵**（KL 控制 + 参考重置） | ProRL + 2505.22617 |
| 最小改动提升 SFT 泛化 | **DFT 一行替换** | 2508.05629 |

### 6.2 三类自动切换信号（机制级）

1. **熵触发**（SRFT）：熵高压 SFT、熵低放 RL；本质是按"探索预算余额"调度。
2. **梯度范数 + 散度触发**（SASR, arXiv:2505.13026）：step-wise 比较两路梯度范数比与 KL 散度。
3. **rollout 正确率触发**（HPT/UPGE）：按当前题 rollout accuracy 决定走 SFT 还是 RL 信号。

**趋势**：从"两阶段顺序"→"按题/按 step 切换"→"单 step 双梯度统一 loss"（CHORD/DFT/UFT）。CHORD（ICLR 2026, arXiv:2508.11408，已并入 ms-swift 4.2.0+）把 SFT 当 on-policy RL 里一个**动态加权辅助项**，对高散度 token 降权，避免 off-policy 数据扰乱已学好的响应模式。

**统一物理判据**：SFT 还在补 base 缺的"覆盖"（mode 不全）→ 用 SFT；覆盖已够、要把质量"再分配"到正确 mode 且仍有熵可花 → 用 RL；两者都需要且互相干扰 → 用 token 级加权的单阶段混合，让监督只调幅度、奖励定方向。

## 7. 对 VLA 真机后训练的启示

1. **「RL 修复 SFT 遗忘」直接成立且更关键**。VLA 的 SFT（模仿演示）同样 OOD 早峰后遗忘——换光照/物体/位姿就崩；RL 微调可作隐式正则修复。已有专门工作：[Continual VLA via RFT (arXiv:2602.10503)]、[VLA-OPD (arXiv:2603.26666)] 均报告 **on-policy RL 比 SFT 更抗遗忘**。
2. **熵坍缩在动作空间更危险**。连续动作策略熵坍缩 = 动作多样性丧失 = mode collapse 到单一抓取姿态。VLA-OPD 用**有界 mode-seeking 目标**，避开 Forward-KL 熵爆炸与 Hard-CE 过早熵坍缩。R=−a·e^H+b 提醒：VLA RL 必须显式管熵。
3. **rollout 极贵 → 必须 off-policy + replay**。把专家演示当"高质量 off-policy 样本"（LUFFY / PrefixRFT / BREAD）、用失败 episode 进 replay（MIFO 的"失败 rollout → SFT buffer"对应 VLA episodic memory），是结构性约束，也是 PLD 走 off-policy 的根本动因。
4. **梯度不对称 → 参数保护 + token 级重加权**。MIFO 的"SFT 梯度大、覆盖 RL 梯度"在 VLA 上很可能成立；对应冻结 RL-critical 参数、对动作 token 做优势/幅度加权（DFT reward rectification + RLSD 方向/幅度解耦可直接迁移）。
5. **不能只看 loss/成功率均值**。Quagmires 警告在 VLA 上加倍：SFT loss 降 ≠ 真机更好；必须看 OOD 成功率、pass@large-k 式多样性指标。

**一句话**：VLA 后训练应是「SFT 求覆盖（求准）→ 在 OOD 峰附近切 RL 求锐化与修复（求泛化），全程显式管熵、用 off-policy replay 缓解 rollout 成本、用 token 级方向/幅度解耦让监督不挤压探索」。
